## Introduction

**Robinhood Chain × Bankr Tools** is an open-source collection of skills and utilities designed to empower AI agents with powerful capabilities on Robinhood Chain — especially for tokenized stocks, cross-chain bridging, portfolio management, and yield optimization.

## 🚀 Quick Start

1. Have an active Bankr agent (Web, Telegram, or X)
2. Install desired skills using natural language
3. Start interacting with your agent using the prompts below

## 🔧 Installation Guide

In your Bankr agent, simply say:

```text
install the rh-portfolio-manager skill from https://github.com/0xMatdis/Robinhood-Chain-Bankr-Tools/tree/main/skills/rh-portfolio-manager
```

Repeat for each skill you want to use.

## Best Practices

- Start with small amounts when testing new automations
- Be specific in your prompts (include amounts, tokens, and frequency)
- Regularly update your installed skills
- Always verify transaction details before execution

## Troubleshooting

- Skill not found → Make sure you copied the full GitHub link
- Command not working → Try more natural and detailed prompts
- Bridge failed → Check gas balance and try smaller amount first
