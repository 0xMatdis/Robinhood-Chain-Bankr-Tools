# RH Bridge Pro

Advanced bridging tool for moving assets and expanding tokens from Base to Robinhood Chain using LayerZero.

## Commands

- "bridge 1000 USDC from base to robinhood"
- "bridge my token to robinhood chain"
- "expand my token to robinhood with liquidity"
- "check my bridge status"
- "bridge with auto liquidity seeding"

## Capabilities

- LayerZero OFT bridging
- Automatic liquidity pool seeding
- Token expansion support
- Real-time bridge status tracking
- Gas optimization
- Error handling and retry logic

## Example Usage

```text
Bridge 2500 USDC from Base to Robinhood Chain with liquidity seeding

Expand my memecoin to Robinhood Chain with 8000 WETH initial liquidity

Check status of my last bridge transaction
```

## Supported Chains
- Base → Robinhood Chain
