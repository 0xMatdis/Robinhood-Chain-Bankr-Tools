# RH Portfolio Manager

Manage and optimize your tokenized stocks portfolio on Robinhood Chain using AI.

## Commands

- "rebalance my portfolio on robinhood"
- "analyze my tokenized stocks"
- "show my portfolio performance on robinhood"
- "set weekly rebalance every monday"
- "DCA 50 USDC into strongest stocks on robinhood every week"

## Capabilities

- Smart rebalancing based on performance and risk
- Portfolio analysis with PnL and correlation
- Automated weekly/monthly strategies
- Gas efficient execution via Bankr
- Support for NVDA, AAPL, TSLA, SPY, etc.

## Example Usage

"Create a balanced portfolio with 500 USDC on Robinhood Chain"
"Rebalance my current holdings to reduce risk"
