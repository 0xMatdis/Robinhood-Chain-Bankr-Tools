# RH Bridge Pro

Advanced bridging and token expansion tool for Base ↔ Robinhood Chain.

## Commands

- "bridge 1000 USDC from base to robinhood"
- "bridge my token to robinhood chain"
- "expand my token to robinhood with liquidity"
- "check my bridge status"

- LayerZero OFT bridging

- Token expansion from Base to Robinhood Chain
- Bridge status tracking
- Gas optimization & error handling
